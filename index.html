02 · measure quality

Holds

Did the agent actually solve the job?

A suite-first evaluation harness. Run representative tasks repeatedly, grade real outcomes, and stop regressions before they reach production.

Artifacts holds.yaml · baseline.json

See how Holds measures ↓ Open on GitHub ↗
terminal · holds 
$ holds run --suite holds.yaml

pass_rate    96%
consistency  92%
threshold    passed

$ holds compare --baseline baseline.json

03 · prevent incidents

Vigil

Are unsafe or expensive behaviors stopped?

A runtime policy SDK for explicit operational controls. Define budgets, allowlists, circuit breakers, routing, and redacted audit behavior.

Artifacts vigil.yaml · audit.jsonl

See how Vigil stops it ↓ Open on GitHub ↗
vigil.yaml 
budgets:
  max_llm_calls_per_workflow: 12
  max_cost_usd_per_workflow: 0.75

controls:
  - type: circuit_breaker
    condition: repeated_equivalent_request
    max_occurrences: 3
