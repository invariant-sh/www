02 · measure quality

Holds

Did the agent actually solve the job?

A suite-first evaluation harness. Run representative tasks repeatedly, grade real outcomes, and stop regressions before they reach production.

Artifacts holds.yaml · baseline.json

Explore Holds on GitHub ↗

Vigil

Are unsafe or expensive behaviors stopped?

A runtime policy SDK for explicit operational controls. Define budgets, allowlists, circuit breakers, routing, and redacted audit behavior.
