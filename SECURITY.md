# Security Policy

This repository is the public static website for [Invariant Labs](https://github.com/invariant-sh)
([getinvariant.sh](https://getinvariant.sh)). It contains HTML, CSS, and assets only.

## Reporting a vulnerability

1. **Do not** open a public GitHub issue with exploit details.
2. Open a [private security advisory](https://github.com/invariant-sh/www/security/advisories/new)
   on this repository.
3. Include: path, reproduction steps, and impact.

We aim to acknowledge reports within a few business days.

Product runtimes have their own policies:

- [Maul](https://github.com/invariant-sh/maul/blob/main/SECURITY.md)
- [Holds](https://github.com/invariant-sh/holds/blob/main/SECURITY.md)
- [Vigil](https://github.com/invariant-sh/vigil/blob/main/SECURITY.md)
